**Pymetrix** (formerly Analyx) is a plug-and-play analytics library written in
pure Python, designed to capture basic website metrics with extension support. It
is compatible with **Django**, **Flask**, **FastAPI**, and **Starlite**.

Read the docs series: [Pymetrix: The Open Source Plug and Play Python Analytics
Library](/blog/pymetrix-home), [An Overview](/blog/pymetrix-overview), and
[Flow classes](/blog/pymetrix-flow).
