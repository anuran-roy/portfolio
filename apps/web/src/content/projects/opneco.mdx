**OpnEco** is a content-writing companion tool offering feedback mechanisms and
keyword-targeting guidance for writers. It provides data analysis and trend
insights.

- **Backend:** Django / SQLite
- **Analytics:** Plotly Express, NLTK, TextBlob, Text2Emotion, Pandas, NumPy
- **Scraping:** Pytrends, requests, BeautifulSoup
- **Frontend:** HTML / Bootstrap / JavaScript, with shell scripting setup
